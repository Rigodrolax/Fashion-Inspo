# Fashion Inspo

App Android pour gérer un album d'inspirations de looks (tags) et une wishlist vêtements.

- **Lookbook** : photos des albums suivis, filtres par tags combinés, sélection multiple (appui long).
- **Rafale** : tagging photo par photo, au swipe.
- **Tags** : familles, renommage, fusion.
- **Wishlist** : catégories, prix, liens, statut, tags reliés aux inspirations. Import depuis une note collée ou partagée.
- **Bilan** : niveau de tagging, look du jour, inspirations absentes de la wishlist.
- **Partager vers Fashion Inspo** : depuis la Galerie, Instagram, Pinterest (photos) ou depuis Notes / une boutique (texte, liens).

## Installer

Chaque push sur `main` compile l'APK via GitHub Actions et le publie dans **Releases** (`FashionInspo.apk`).
Sur le téléphone : télécharger l'APK, autoriser l'installation d'applis inconnues pour Chrome, installer.
Les mises à jour s'installent par-dessus sans perdre les données (même clé de signature, dans `keystore/`).
